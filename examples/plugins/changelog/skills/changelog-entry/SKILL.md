## name: changelog-entry description: Adds an entry for a change to CHANGELOG.md. Use when the user asks to log, note or record a change, fix or feature in the changelog. Not for deciding whether a release is ready (use release-check).

# Changelog entry

1. Read `CHANGELOG.md`. If it has no `## Unreleased` section, add one above the newest release.
2. Add one bullet under `## Unreleased`, in the past tense, naming what changed for the user, not the code that changed.
3. Leave released sections untouched.
